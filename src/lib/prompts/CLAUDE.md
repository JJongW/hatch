# src/lib/prompts/ — 프롬프트 (B · C)

담당: `chain-author` (체인) · `tool-builder` (도구)

## 파일 지도
- `chain/<단계>.ts` — 체인 단계 프롬프트
- `tools/<도구>.ts` — PO 도구 프롬프트
- 공통 상황 블록(아이디어 · 기획안 요약)은 `context.ts` 하나로

## 규칙
- **프롬프트 문자열은 프로젝트 전체에서 여기에만**
- 문자열 상수 + 짝이 되는 출력 스키마 이름만 export. 함수 · 호출 없음
- 지원 정보가 없으면 지어내지 말고 `[확인 필요: ○○]`
- 사용자가 쓴 프롬프트 문장은 바꾸지 말고 바꿀 점은 제안만

## 하지 말 것
- 합계 · 개수 · 순위 계산을 AI에게 맡기는 문장
- 키 · 개인정보
