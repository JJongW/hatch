# src/lib/storage/ — 아이디어 · 문서 저장 (A)

담당: `ui-builder`

## 역할
아이디어와 생성된 문서(기획안 · PRD 등)를 저장 · 조회. 화면은 이 폴더 함수만 부른다.

## 규칙
- 처음엔 서버 없이 브라우저 저장. 저장소 종류는 A spec에서 확정
- 바깥에 보이는 건 함수(인터페이스)만. 저장 방식이 바뀌어도 호출부는 그대로
- 데이터 모양(타입)은 이 폴더에 정의하고 버전 필드를 둔다 (나중에 옮길 때 대비)
- 읽기 실패 · 빈 저장소에서도 화면이 깨지지 않게 빈 값 반환

## 갈아탈 신호 (README)
- 여러 기기에서 같은 데이터 필요 → DB(Supabase 등)로. 인터페이스는 유지

## 하지 말 것
- 화면 컴포넌트 import
- 개인정보 · 키 저장
