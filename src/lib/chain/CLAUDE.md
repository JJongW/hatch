# src/lib/chain/ — 문서 생성 체인 (B)

담당: `chain-author` · 단계 추가 절차: `chain-step` 스킬

## 체인
아이디어 → 상세 기획안 → 커리큘럼 → PRD → 기능명세서 → 개발 프롬프트 / 디자인 프롬프트
("커리큘럼"의 뜻은 B spec에서 확정)

## 규칙
- 단계 하나 = 파일 하나: 입력 타입 · 출력 JSON 스키마 · 쓸 프롬프트 이름 · 앞 단계
- 각 단계는 앞 단계 결과만 입력으로 받는다 (건너뛰지 않음)
- 실제 생성 호출은 `bridge/` 클라이언트 한 곳을 거친다
- AI 출력은 스키마 검사 후 저장. 실패하면 한국어 한 줄 에러

## 하지 말 것
- 이 폴더에 프롬프트 문장 (→ `src/lib/prompts/`)
- 화면 코드, 저장 직접 접근 (→ `src/lib/storage/` 함수)
