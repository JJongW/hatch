# PO 도구 하나 추가하기

> 공통 틀은 C 단계 첫 PR에서 만든다. 그 PR이 머지되면 아래 경로 · 이름을 실제 코드에 맞게 갱신한다.

## 전제
- 공통 틀(기획안 선택 + 입력 → 실행 → 결과)이 `main`에 있다
- 이 도구의 이슈(`area:tools`)와 브랜치 `feat/<n>-<도구>`가 있다

## 순서
1. **판단 vs 계산 나누기** — AI가 판단할 것(분류 · 반론 · 제안)과 코드가 계산할 것(점수 · 합계 · 순위 · 전후 차이)을 표로 적는다
2. **출력 스키마** — AI 출력 JSON 모양을 먼저 정한다 (범위가 있는 점수는 최소 · 최대 명시)
3. **계산 함수 + 테스트** — 2의 출력을 받아 계산하는 순수 함수. 테스트 먼저 (범위 밖 점수 자르기 포함)
4. **프롬프트** — `src/lib/prompts/tools/<도구>.ts`. 상황 블록은 `context.ts` 재사용
5. **화면** — `src/app/tools/<도구>/`. 공통 틀에 입력 · 결과 영역만 채운다 (`montage-ui` 스킬)
6. **네비바 등록** — 공통 틀이 정한 방식으로 한 줄
7. **검증** — `npm run lint && npm run typecheck && npm run build`, 실제로 기획안 하나 골라 실행
8. `hatch-reviewer` → PR

## 하지 말 것
- 공통 틀 · 다른 도구 폴더 수정 (필요하면 별도 이슈)
- AI가 낸 합계 · 순위 표시
