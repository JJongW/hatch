# 모든 화면의 섹션 제목과 테두리 상자를 같은 모양으로 맞춘다

**날짜**: 2026-11-02
**관련 파일**: section-title.tsx, page-header.tsx, panel, tool-frame.tsx, usage-view.tsx, survey-form.tsx, idea-summary.tsx, context-panel.tsx, code-block.tsx, mermaid-block.tsx

## What — 무엇이 달라졌나
페이지 제목, 섹션 제목, 테두리로 묶은 상자가 모든 화면에서 같은 크기, 같은 여백으로 보인다. 아이디어 상세의 맥락 제목 옆 "수정"처럼 섹션에 딸린 버튼은 제목 줄 오른쪽에 글자 버튼으로 붙는다. 섹션 제목은 조금 커져(18px) 본문과 구분이 분명해졌다.

## Why — 왜 필요했나
디자인 시스템을 Montage로 정했지만 제목과 상자를 화면마다 직접 그려서, 같은 "섹션 제목"이 화면마다 크기와 위 여백이 달랐다. 사용자는 화면이 "정돈되지 않았고 위계가 없다"고 느꼈다. 테두리 상자도 다섯 곳에 복사돼 있어 하나를 고치면 나머지가 어긋났다.

## 판단 근거
- 화면 구조를 바꾸기 전에 바탕부터 맞춘다. 제목과 상자가 같아야 다음 단계(아이디어 상세 재구성)에서 위계를 세울 수 있다
- 모양을 새로 만들지 않고 Montage의 섹션 머리를 쓴다. 원티드 화면과 같은 위계를 따르게 된다
- 테두리 상자는 Montage에 맞는 부품이 없어 하나만 만들고 모든 곳이 그것을 쓴다
