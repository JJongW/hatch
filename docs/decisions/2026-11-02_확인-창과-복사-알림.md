# 확인 창과 복사 알림을 서비스 화면 안에서 보여 준다

**날짜**: 2026-11-02
**관련 파일**: use-confirm-submit.tsx, idea-detail.tsx, doc-card.tsx, decisions-panel.tsx, code-block.tsx, mermaid-block.tsx

## What — 무엇이 달라졌나
휴지통으로 옮기기, 문서 다시 만들기, 결정 지우기를 누르면 브라우저 기본 확인 창 대신 서비스 안의 확인 창이 뜬다. 제목에 무엇을 할지, 설명에 무엇이 남는지 적혀 있고 버튼은 "취소"와 할 일 이름("휴지통으로", "새로 만들기", "지우기")이다. 코드와 구성도를 복사하면 버튼 글자가 바뀌는 대신 화면 아래에 "복사했어요" 알림이 잠깐 뜬다. 복사가 막히면 그 이유를 알려 준다. 결정 줄에서 지우기를 누르면 수정 폼이 함께 열리던 문제도 고쳤다.

## Why — 왜 필요했나
브라우저 기본 확인 창은 서비스와 모양이 달라 갑자기 다른 프로그램이 끼어든 것처럼 보였고, 버튼이 "확인"과 "취소"뿐이라 무엇을 확인하는지 다시 읽어야 했다. 복사 결과는 버튼 글자만 1.6초 바뀌어서 눈을 떼면 놓쳤고, 구성도는 복사가 막혀도 아무 반응이 없었다.

## 판단 근거
- 되돌리기 어려운 동작일수록 확인 버튼에 동작 이름을 쓴다. 결정 지우기는 빨간 글자로 구분한다
- 취소는 왼쪽, 실행은 오른쪽. 같은 화면 안 다른 버튼과 순서를 맞춘다
- 복사 결과는 버튼 자리를 바꾸지 않고 알림으로 보여 준다. 버튼 폭이 흔들리지 않고, 화면 읽기 프로그램에도 알림으로 전달된다
