# 생성 대기 화면에 예상 순서를 보여 주고, 목록과 카드에 움직임을 준다

**날짜**: 2026-11-02
**관련 파일**: running-note.tsx, running-steps.ts, doc-card.tsx, idea-list.tsx, idea-card.tsx, doc-tabs.tsx, globals.css, 도구 정의 4개

## What — 무엇이 달라졌나
문서나 도구 결과를 만드는 1~2분 동안, 반짝이는 안내 문구와 함께 "예상 순서"가 한 줄씩 올라온다. 다 만들면 대기 화면이 "28초 걸려 만들었어요" 한 줄로 접히고, 누르면 예상 순서를 다시 펼쳐 본다. 아이디어 목록은 위에서부터 차례로 나타나고, 카드는 마우스를 올리면 배경이 바뀌고 누르면 살짝 눌린다. 문서 탭을 바꾸면 내용이 부드럽게 바뀐다.

## Why — 왜 필요했나
사용자가 "원했던 모션의 효과가 하나도 적용되어 있지 않다"고 짚었다. 지금까지 움직임은 로고 하나뿐이었다. 특히 생성 대기 중에는 회전 아이콘과 지난 시간만 있어 멈춘 건지 도는 건지 알기 어려웠고, 회전 아이콘은 크기가 0으로 깨져 보이지도 않았다. 목록과 카드는 눌러도 반응이 없어 누를 수 있는 것인지 알기 어려웠다.

## 판단 근거
- 생성기는 중간 진행을 알려 주지 않는다. 그래서 진행률 막대처럼 꾸미지 않고 "예상 순서예요. 실제 진행과 다를 수 있어요"라고 그대로 적었다. 기다리는 사람에게 지금 무엇을 하는 중일지 그려 주되 거짓 정보는 주지 않는다
- 끝난 뒤 대기 화면을 지우지 않고 한 줄로 접어, 얼마나 걸렸는지와 무엇을 했는지 남긴다
- 목록 등장은 짧게(0.3초) 하고 10번째부터는 더 늦추지 않는다. 읽는 앱이라 움직임이 기다림이 되면 안 된다
- 움직임 줄이기를 켠 사람에게는 모든 움직임을 끄고 바로 최종 모습을 보여 준다
- 페이지 이동이나 스크롤에 따른 등장은 넣지 않았다. 읽는 흐름을 방해한다
