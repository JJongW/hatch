# 문서 생성은 내 맥의 Claude로

**날짜**: 2026-10-28
**관련 파일**: run.ts, README.md

## What — 무엇이 달라졌나
아이디어 한 줄에서 기획안 · PRD 같은 문서를 만들 때, 내 맥에 로그인된 Claude가 만든다. API 키를 따로 넣지 않는다.

## Why — 왜 필요했나
PO 혼자 쓰는 도구인데 API 키를 발급하고 사용량 요금을 따로 관리하면 쓰기 전부터 문턱이 생긴다. 이미 쓰고 있는 Claude 구독으로 바로 돌아가야 했다.

## 판단 근거
- 맞바꾼 것: 인터넷에 올린 주소만으로는 생성할 수 없다. 앱은 맥에서 돌리고 다른 기기는 맥에 접속한다 (→ [Tailscale Serve](2026-10-28_bridge-보류-tailscale-serve.md))
- 한 번에 하나만, 5분 제한 — 로컬 자원을 쓰므로 동시에 여러 개를 돌리지 않는다
- 갈아탈 신호: 여러 사람이 동시에 써야 하면 API 방식으로 옮긴다
