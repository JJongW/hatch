# 인터넷 주소는 읽기 전용 데모로

**날짜**: 2026-10-28
**관련 파일**: demo.ts, actions.ts, app-shell.tsx, demo-data/

## What — 무엇이 달라졌나
설치 없이 주소만으로 Hatch를 둘러볼 수 있다. 샘플 아이디어 3개, 6단계 문서 전체, PO 도구 4종의 실제 결과(PRD 재리뷰 · VOC 24건 · 지표 · 협상 2라운드)가 들어 있다. 저장 · 생성 버튼을 누르면 "내 맥에서 실행하면 직접 만들 수 있어요"라고 안내한다.

## Why — 왜 필요했나
제출물에 배포 주소가 필요하다. 그런데 생성은 내 맥의 Claude로만 된다([결정](2026-10-28_로컬-claude-생성.md)). 아무것도 없는 빈 주소를 올리면 심사자가 무엇을 하는 서비스인지 볼 수 없다.

## 판단 근거
- 맞바꾼 것: 데모에서 직접 생성은 못 한다 → 생성 장면은 시연 영상으로 보여 준다
- API 키를 붙여 공개 생성을 여는 안은 뺐다: 구조를 바꿔야 하고, 공개 주소에서 누구나 내 비용으로 생성하게 된다
- 샘플은 지어낸 결과가 아니라 실제 claude로 만든 결과다 — 둘러보는 것만으로 결과 품질을 판단할 수 있다
- 갈아탈 신호: 다른 사람이 직접 생성해 봐야 하면(사용자 테스트) API 생성 + 사용 횟수 제한을 붙인다
