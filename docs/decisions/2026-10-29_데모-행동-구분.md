# 데모에서는 할 수 있는 것만 버튼으로

**날짜**: 2026-10-29
**관련 파일**: demo.tsx, app-shell.tsx, idea-form.tsx, doc-card.tsx, idea-detail.tsx, tool-frame.tsx, start/

## What — 무엇이 달라졌나
인터넷 데모에서 저장 · 만들기 · 편집 · 실행 · 휴지통 버튼이 사라지고, 그 자리에 "내 환경에서 사용하기"가 놓인다. 도구 화면은 맨 위에 "샘플 결과 보기"가 있어 한 번에 샘플 결과로 간다. 배너와 안내 버튼은 GitHub 대신 앱 안의 시작 안내 페이지(되는 것 · 안 되는 것 · 준비물 · 실행 명령)로 간다.

## Why — 왜 필요했나
외부 피드백: "읽기 전용"이라고 쓰여 있어도 저장 · 실행 버튼이 진짜 버튼처럼 보여, 눌러 보고 나서야 안 된다는 걸 알았다. 배너의 GitHub README 링크는 저장소가 비공개라 외부 사람에게 404였다.

## 판단 근거
- 막힌 버튼을 보여 주고 오류로 알리기보다, 처음부터 할 수 있는 행동만 보여 준다
- 도구는 처음 온 사람이 할 일이 "결과 구경"뿐이다 → 그 행동을 맨 위 한 번의 클릭으로
- 시작 경로는 저장소 공개 여부와 상관없이 앱 안에서 끝난다 (공개는 이력 검사 뒤 따로 결정)
- 맞바꾼 것: "예시 입력 불러오기"는 이번에 못 했다. 샘플 결과를 만들 때 쓴 입력이 저장돼 있지 않아서, 지어낸 입력을 보여 줄 수는 없다
