# 흐름 체험에서는 기획안 다음 할 일이 확인 질문 정리

**날짜**: 2026-11-03
**관련 파일**: summary/index.ts, next-band.tsx, questions-panel.tsx, try-flow.tsx

## What — 무엇이 달라졌나
- 흐름 체험(/try)에서 기획안을 만든 뒤 "다음 할 일"이 고객 의견 정리 대신 확인 질문을 가리킨다. 버튼을 누르면 확인 질문 탭이 열린다.
- 확인 질문 탭 문구를 문장으로 풀었다. "새로 생긴 확인 필요 N개"는 "질문을 만든 뒤 문서에 새 [확인 필요]가 N개 생겼어요", "질문에서 빠진 것: 라벨 없는 표시 N곳"은 "이름 없이 [확인 필요]만 적힌 N곳은 질문으로 만들지 않았어요"로 바꿨다.
- 체험에서는 질문 목록을 만들자마자 "새 [확인 필요]" 줄이 뜨지 않는다.

## Why — 왜 필요했나
운영 /try 점검에서 과제 순서(질문 → 고객 의견)와 "다음 할 일"이 어긋났다. 질문을 만들자마자 "새로 생긴 확인 필요 1개"와 "라벨 없는 표시 4곳"이 같이 떠서 무슨 뜻인지 알기 어려웠다 (#113).

## 판단 근거
- 상세 화면의 규칙 순서는 그대로 둔다. 질문 목록 여부(`questionsMade`)는 체험만 넘긴다. 상세에서도 질문을 먼저 권하는 게 맞다고 보이면 page.tsx에서도 넘기면 된다.
- 예시 질문은 예시 기획안보다 먼저 만들어져 라벨 하나가 빠져 있다. 예시 파일을 고치지 않고, 체험에서 질문을 만들 때 지금 문서의 라벨을 더한다.
