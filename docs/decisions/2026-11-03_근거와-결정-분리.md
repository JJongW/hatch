# 고객에게 들은 답은 근거, 팀이 고른 답은 결정

**날짜**: 2026-11-03
**관련 파일**: storage/evidence.ts, storage/decisions.ts, questions-panel.tsx, evidence-form.tsx, decision-form.tsx, status-cards.tsx, prompts/questions.ts

## What — 무엇이 달라졌나
확인 질문 중 고객에게 물을 것과 담당자에게 확인할 것에 "답 적기"를 누르면 들은 내용과 출처(인터뷰 · VOC · 설문 · 담당자 확인 · 기타, 누구에게 · 언제)를 근거로 저장한다. 결정 수, 결정 탭, 기획안의 "정한 것"은 바뀌지 않는다. 저장하면 "이 근거로 어떤 결정을 내릴까요?"가 뜨고, 고르면 그 근거와 연결된 결정을 적는다. 결정에는 제안 · 정함 · 보류가 있고, 제안은 기획안에 넣지 않는다. 확인 질문은 세 갈래(고객 · 담당자 확인 · 팀이 정할 것)로 나뉘고, 팀이 정할 것은 바로 결정으로 적는다. 현황은 문서 · 확인 질문 · 근거 · 결정 4칸이다.

## Why — 왜 필요했나
고객 답이 결정으로 저장돼 결정 수와 기획안의 "정한 것"이 늘었다. 고객 한 명이 "가격부터 본다"고 말한 것은 관찰이지 팀이 고른 방향이 아니다. 사용자 요청(2026-11-03): 근거 저장만으로 결정 상태가 바뀌면 안 되고, 결정은 내용 · 이유 · 상태 · 연결 근거를 가진다.

## 판단 근거
- 결정 파일에 종류 칸을 더하는 대신 파일을 나눴다. 기획안 입력 해시를 결정만으로 계산하는 지금 규칙을 건드리지 않아, 근거를 적어도 문서가 "예전 기준"이 되지 않는다
- 예전에 고객 답으로 저장된 결정은 옮기지 않는다. 어느 것이 관찰이었는지 코드로 알 수 없고, 사용자 데이터를 함부로 바꾸지 않는다
- 제안은 공유 링크에 내보내지 않는다. 팀 결정이 아니고, 공유 화면(Vercel)은 정함 · 보류만 받는다
- 근거를 문서 생성 입력에 넣는 것은 변경 원인 표시(#126)와 같이 한다. 지금 넣으면 근거만 바뀌어도 "앞 문서가 바뀌었어요"가 뜬다
