# 참가자 설문 (구글 폼으로 옮겨 쓰기)

테스트가 끝난 직후 참가자가 **혼자** 채운다 (3분). 웹 설문(`/survey`, #71)은 `src/lib/survey/questions.ts`가 기준이다. 문항을 바꾸면 이 파일과 같이 고친다. 진행자의 관찰 기록지(`record-sheet.md`)와 따로 받아, 본 것과 참가자가 느낀 것을 맞대 본다.
진행자는 자리를 비켜 준다. 앞에 있으면 점수가 후해진다.

## 폼 설정

- 이메일 수집 끔, 로그인 요구 끔. 이름, 회사, 연락처를 묻는 칸을 만들지 않는다
- 응답은 스프레드시트로 연결해 `results.md` 표를 채울 때 쓴다
- 아래 문구는 참가자가 읽는 글이라 가운데 점을 쓰지 않는다

표기: **[필수]** 필수 응답, 유형은 구글 폼 질문 유형 이름

## 1. 나에 대해

폼 설명:
> 방금 본 Hatch 데모에 대한 설문이에요. 6문항이고 3분쯤 걸려요. 정답은 없어요. 이름이나 회사는 묻지 않아요.

참가자는 데모만 본다(생성은 안 됨). 그래서 기능을 써 본 소감은 묻지 않는다. 묻는 것은 두 가지다.
- 이 문제를 실제로 겪나 (3, 4번 = 문제 정의 근거)
- 데모만 보고 무엇을 하는 서비스인지 알겠나 (5, 6번)

| # | 질문 | 유형 | 선택지 |
| --- | --- | --- | --- |
| 1 | 무슨 일을 하세요? **[필수]** | 객관식 | 서비스 기획(PO, PM), 사업 기획, 마케터, 디자인, 개발, 기타 |
| 2 | 기획 문서를 쓸 때 ChatGPT나 Claude 같은 AI를 써 봤나요? **[필수]** | 객관식 | 자주 써요, 가끔 써요, 안 써 봤어요 |
