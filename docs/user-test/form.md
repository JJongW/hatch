# 참가자 설문 (구글 폼으로 옮겨 쓰기)

테스트가 끝난 직후 참가자가 **혼자** 채운다 (5분). 진행자의 관찰 기록지(`record-sheet.md`)와 따로 받아, 본 것과 참가자가 느낀 것을 맞대 본다.
진행자는 자리를 비켜 준다. 앞에 있으면 점수가 후해진다.

## 폼 설정

- 이메일 수집 끔, 로그인 요구 끔. 이름, 회사, 연락처를 묻는 칸을 만들지 않는다
- 첫 칸의 참가자 번호(P1~P5)는 진행자가 알려 준다. 이 번호로 기록지와 짝을 맞춘다
- 응답은 스프레드시트로 연결해 `results.md` 표를 채울 때 쓴다
- 아래 문구는 참가자가 읽는 글이라 가운데 점을 쓰지 않는다

표기: **[필수]** 필수 응답, 유형은 구글 폼 질문 유형 이름

## 2. 과제별로 돌아보기

설명: 오늘 해 본 과제예요. 안 한 과제는 "안 함"을 골라 주세요.

과제 행 (두 질문 모두 같은 행):
1. 아이디어 남기기
2. 맥락(대상 고객, 목표) 적기
3. 기획안 만들고 지금 내릴 결정 찾기
4. 확인이 안 된 부분을 질문으로 정리하기
5. 답한 내용을 기획안에 반영하기
6. PRD 검토받고 반론 반영하기
7. 고객 의견 정리하기

| # | 질문 | 유형 | 열 |
| --- | --- | --- | --- |
| 2-1 | 각 과제를 어떻게 마쳤나요 **[필수]** | 객관식 그리드 | 혼자 해냄, 도움 받아 해냄, 못 함, 안 함 |
| 2-2 | 각 과제가 얼마나 쉬웠나요 **[필수]** | 객관식 그리드 | 1 매우 어려움, 2, 3, 4, 5 매우 쉬움, 안 함 |
