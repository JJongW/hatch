# 도구 결과 요약 화면: 재리뷰 비교, VOC 거르기 (2026-11-02)

이슈 #82 (공통 틀), #83 (PRD 재리뷰 비교, 조사 보고서 3번), #84 (VOC 거르기, 조사 보고서 5번).
도구 결과는 마크다운 한 덩어리(`render`)라 막대나 누르는 칩을 붙일 수 없다. 공통 틀에 자리를 하나 만들고 두 도구가 쓴다.
PR은 셋으로 나눈다 (공통 틀은 도구 PR에 섞지 않는다, `src/app/tools/CLAUDE.md`).

## 1. 공통 틀: 결과 요약 자리 (#82)
- `loadToolPage`의 `current`에 계산 결과 `data`를 같이 싣는다 (저장 파일 머리말에 이미 있다)
- `ToolFrame`에 `resultSummary?: ReactNode`. 도구 페이지(서버)가 `current.data`로 요약 화면을 만들어 넘긴다. 결과 상자 맨 위, 마크다운 위에 놓인다
- 함수는 서버에서 클라이언트로 못 넘기므로 "data → 화면" 함수 대신 다 만든 화면을 넘긴다
- `data` 모양이 다르면(예전 결과, 깨진 파일) 요약 화면은 그리지 않는다. 마크다운은 그대로 보인다
- 마크다운 본문은 바꾸지 않는다. 저장 파일은 앱 밖에서도 읽는 기록이다

## 2. PRD 재리뷰 비교 (#83)
- 이전 결과(`prev`)가 있을 때만 보인다
- 표: 기준 5개 + 전체. 칸은 "기준 | 이전 → 지금 | 막대 | 차이"
  - 막대: 5점 만점 기준. 이전은 옅은 막대, 지금은 진한 막대를 겹친다
  - 차이: "▲ 0.7"(오름, 초록), "▼ 0.2"(내림, 빨강), "그대로"(회색). 색만으로 구분하지 않게 기호와 글자를 같이 쓴다
  - 한쪽이 "응답 없음"(null)이면 그 칸은 "응답 없음", 막대와 차이 없음
- 제목 "지난 리뷰와 비교". 차이 계산은 화면에서 하지 않고 이미 저장된 `criteria`, `overall`, `prev`를 쓴다 (빼기만 화면에서)
- 막대는 장식이라 `aria-hidden`, 숫자 칸이 같은 정보를 준다

## 3. VOC 거르기 (#84)
- 칩: 전체 / 심각 (평균 심각도 3 이상) / 자주 나옴 (5건 이상). 칩마다 해당 주제 수를 붙인다. 하나만 고른다 (기본 전체)
- 표: 순위 | 주제 | 건수 | 평균 심각도 | 점수(합). 걸러지면 순위는 원래 순위 그대로 둔다
- 걸러서 0개면 "이 조건에 맞는 주제가 없어요"
- 기준 값은 칩 글자에 그대로 적는다 (숫자를 숨기지 않는다). 계산은 이미 저장된 `topics`의 `average`, `count`
- 칩은 Montage `Chip`(선택 상태는 `aria-pressed` 또는 Montage가 주는 선택 속성), 표는 Montage 표가 없으면 시맨틱 `table`과 토큰 색
- 마크다운의 "출발 순위"와 겹치지만, 요약은 눌러 보는 용도이고 마크다운은 기록이다

## 4. 하지 않는 것
- 반론 수 비교 (이전 결과에 심각도별 개수가 저장돼 있지 않다. 필요해지면 `compute` 저장 형식부터)
- 협상 라운드 비교 (같은 자리를 쓰면 된다. 지금은 범위 밖)
- 칩 여러 개 동시 선택, 정렬 바꾸기
