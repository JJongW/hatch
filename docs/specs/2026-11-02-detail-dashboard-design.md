# 아이디어 상세 재구성: 현황판 + 탭 (2026-11-02)

근거: [화면 비평](https://claude.ai/artifact/KVVipAL8Q8nEj2Y6JPyAPU) 우선순위 1, 2. [Montage 점검](2026-11-02-montage-audit.md) 4절 첫 표.
PR 1a(#88, `SectionHeader`, `Panel`) 위에서 만든다. 이슈 2a #91, 2b #92.

## 1. 문제 (지금)
- 한 줄로 3,786px. 이 화면의 결과물인 문서 7개가 2,300px 아래에 있다
- "모르는 것"이 네 번 나온다: 맥락 칸 "확인된 근거와 모르는 것", 결정 칸 "아직 안 정한 것", 확인 질문 29개, 문서 본문 "확인 필요" 절
- 확인 질문 29개가 글머리표. 출처는 작은 회색 글자
- 가장 중요한 "추천 다음 행동"이 4칸 상자 중 오른쪽 아래
- 문서 탭 7개가 가로로 붙고, 완료 탭이 흐려 비활성처럼 보인다

## 2. 구조 (위에서 아래)
1. **머리**: 폴더 배지, 제목, 메모(PageHeader). 오른쪽에 수정 버튼. 그 아래 한 줄에 맥락 칩(목표 고객, 목표 지표 …, 읽기 전용 `Chip`)과 "맥락 수정" `TextButton`. 사용량은 머리 오른쪽 아래 caption 링크
2. **다음 할 일 띠**: `Panel` 한 장. 왼쪽 문장(지금 NextCell 문구 그대로), 오른쪽 주 `Button` 하나. 모바일은 위아래
3. **현황 3칸**: `Panel` 3개 (모바일 1열)
   | 칸 | 큰 숫자 | 캡션 | 누르면 |
   | --- | --- | --- | --- |
   | 문서 | 완료 수 / 7 | 다시 만들 것 n개 (없으면 "모두 최신") | 문서 탭 |
   | 확인 질문 | 남은 질문 수 | 답한 것 n개 (질문을 안 만들었으면 "[확인 필요] n곳") | 확인 질문 탭 |
   | 결정 | 정한 것 수 | 아직 안 정한 것 n개 | 결정 탭 |
4. **본문 탭** (`Tab`, 4개): 문서 / 확인 질문 / 결정 / 문제와 근거. 처음 탭은 문서

### 탭 안
- **문서**: 넓은 화면(1024px 이상)은 왼쪽 세로 `List` + `ListCell`(선택 표시, trailing에 상태 `ContentBadge`: 완료 / 앞 문서가 바뀜 / 만드는 중 / 다음 차례 / 대기) + 오른쪽 문서 본문. 좁은 화면은 지금 가로 탭 그대로(가로 스크롤). 상태 요약 한 줄(`summaryLine`)은 목록 위
- **확인 질문**: 묶음마다 `Accordion` (고객에게 물을 것, 담당자 역할별). 제목에 개수. 고객 묶음만 처음 펼침. 줄은 `ListCell`: 질문, description에 "라벨 (n곳)", trailing에 "답 적기"(데모에선 없음). 답 적기를 누르면 그 줄 아래 지금 DecisionForm. 질문 만들기 전 상태와 "새로 생긴 확인 필요"는 지금 그대로
- **결정**: "아직 안 정한 것", "정한 것과 보류한 것" 두 묶음 `List` + `ListCell`. 정하기, 수정, 지우기, 직접 추가는 지금 그대로
- **문제와 근거**: 해결하려는 문제 문단, 고객 근거 한 줄(VOC), 모르는 것은 개수 한 줄 + "확인 질문 탭에서 보기" 링크 (목록을 여기 다시 쓰지 않는다)

### 탭 이동
- 현황 칸, 다음 할 일 버튼("기획안 확인하기" 등)은 해당 탭(문서면 그 문서까지)을 연다
- 탭 상태는 화면 안 상태만. 주소에 넣지 않는다 (공유할 일이 생기면 `?tab=` 추가)

## 3. 계산 (코드가 한다)

- 문서 상태는 지금 `chainProgress`를 그대로 쓴다
