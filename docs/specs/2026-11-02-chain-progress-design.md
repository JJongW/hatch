# 문서 체인 진행 표시 (2026-11-02)

이슈 #78. 근거: 2026-10-29 조사 보고서 2번 "문서 6개 진행 현황" (Beautiful UI Task Rows).
사용자가 고른 모양: **지금 문서 탭을 진행 표시로 키운다** (따로 세로 목록을 두지 않는다. 탭과 정보가 겹치고 화면이 길어진다).

## 1. 문제
- 상세 화면의 문서 탭에 점과 "있음 / 아직 없음"만 있어, 체인이 어디까지 왔고 다음에 무엇을 만들지 한눈에 안 들어온다
- 탭 상태 글씨가 너무 옅다 (디자인 평가에서 대비 1.69로 지적)
- 아이디어 목록 카드에는 마지막 문서 이름만 있어 얼마나 남았는지 모른다

## 2. 문서 상태 (탭마다 하나)
위에서부터 먼저 맞는 것 하나.

| 상태 | 조건 | 표시 | 글자 |
| --- | --- | --- | --- |
| 만드는 중 | 지금 생성 중인 문서 | 파란 점이 천천히 깜빡임 | 만드는 중 |
| 앞 문서가 바뀜 | 내용이 있고 앞 문서가 그 뒤에 바뀜 | 주황 점 | 앞 문서가 바뀜 |
| 완료 | 내용이 있음 | 파란 체크 | 완료 |
| 다음 차례 | 내용이 없고, 앞 문서가 있고(기획안은 아이디어), 체인 순서에서 이런 문서 중 첫 번째. 생성 중이면 없음 | 파란 테두리 원 | 다음 차례 |
| 대기 | 그 밖에 내용이 없음 | 회색 테두리 원 | 대기 |

- "다음 차례"는 체인 순서로 정한다. 상단 "추천 다음 행동"(VOC 모으기, PRD 리뷰 등 도구까지 보는 것)과는 따로다
- 상태 글씨는 `foreground.neutral.secondary` (지금 tertiary는 대비 부족). "다음 차례"만 `foreground.brand.primary`로 강조
- 체인 순서상 처음 빈 문서는 앞 문서가 늘 있으므로, 생성 중이 아니면 빈 문서가 있는 한 다음 차례가 하나 있다
- 깜빡임은 줄인 모션 설정이면 멈춘다. "만드는 중" 글자는 그대로 보인다

## 3. 요약 한 줄 (탭 바로 위)
- 기본: "7개 중 3개 완료, 다음 차례는 PRD"
- 생성 중: "7개 중 3개 완료, 지금 PRD 만드는 중" (다시 만드는 중이면 완료 수는 그대로)
- 모두 있으면: "7개 모두 완료"
- 완료 수는 내용이 있는 문서 수 (앞 문서가 바뀐 문서도 포함)

## 4. 아이디어 목록 카드
- 진행 배지 옆에 "3/7"을 회색 작은 글자로 붙인다 (스크린리더에는 "문서 7개 중 3개 완료"). 문서가 하나도 없으면 붙이지 않는다

## 5. 하지 않는 것
- 탭 줄을 세로 목록이나 단계 막대로 바꾸기
- 도구 결과(VOC, PRD 리뷰)를 진행에 넣기

## 6. 검증
- 단위: 상태 계산 (빈 체인, 중간, 바뀜, 생성 중, 모두 완료, 디자인 프롬프트처럼 앞 문서가 없는 경우)
- 브라우저(agent-browser): 상세 탭 상태와 요약 줄, 생성 중 표시, 목록 카드 "3/7", 휴대폰 폭, 줄인 모션, 콘솔 오류
- `npm run lint && npm run typecheck && npm test && npm run build`
